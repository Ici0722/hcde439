Assignment 2: Interactive Light-Up Toy

For this assignment, I designed and built an interactive light-up toy using an Arduino Uno, one RGB LED, two additional LEDs, a push button, resistors, and a breadboard. The RGB LED cycles through red, green, and blue, gradually fading in and out. The two additional LEDs create a flashing effect alongside the RGB LED. A push button allows the user to turn the light show on and off.

01. Schematic

I created a schematic to plan the connections between the Arduino, LEDs, resistors, and button. My circuit includes one RGB LED with three independently controlled color channels, one yellow LED, and one white LED. Each LED channel has its own current-limiting resistor. The push button uses Arduino's internal pull-up resistor.

Resistor Calculations

I used Ohm's Law to calculate the appropriate current-limiting resistors for the LEDs. I chose a target current of approximately 10mA per LED channel.

R = (Vsource - Vforward) / I

Vsource = 5V

Target current = 10mA = 0.01A

Red and Yellow LEDs

The red and yellow LEDs have an assumed forward voltage of approximately 2.0V.

R = (5V - 2V) / 0.01A = 300Ω

I selected 330Ω resistors to keep the expected current below 10mA.

I = (5V - 2V) / 330Ω = 9.09mA

Green LED

I assumed a forward voltage of 3.2V for the green channel of the RGB LED.

R = (5V - 3.2V) / 0.01A = 180Ω

I used an available 330Ω resistor, which limits the expected current to:

I = (5V - 3.2V) / 330Ω = 5.45mA

Blue LED

I assumed a forward voltage of 3.3V for the blue channel of the RGB LED.

R = (5V - 3.3V) / 0.01A = 170Ω

I selected a 220Ω resistor to limit the current through the blue LED.

I = (5V - 3.3V) / 220Ω = 7.73mA

White LED

I measured a forward voltage of 2.85V across the white LED while it was on.

R = (5V - 2.85V) / 0.01A = 215Ω

I used a 220Ω resistor, giving an estimated current of:

I = (5V - 2.85V) / 220Ω = 9.77mA

Button Current Limitation

I used Arduino's built-in INPUT_PULLUP mode for the push button instead of an external resistor.

The internal pull-up resistor is typically between 20kΩ and 50kΩ. When the button is pressed, pin 2 is connected to GND.

I = 5V / 20,000Ω = 0.25mA

I = 5V / 50,000Ω = 0.10mA

The internal pull-up resistor limits the button current to approximately 0.10–0.25mA. This prevents a direct short circuit between 5V and GND when the button is pressed.

02. Circuit Implementation

I assembled the circuit on a breadboard using an Arduino Uno. The RGB LED uses three PWM output pins to control brightness and color. The yellow and white LEDs provide additional lighting effects. All five LED channels have current-limiting resistors and share a common ground.

03. Firmware

I modified Arduino's built-in Fade example to control multiple LEDs and respond to button input. The program uses analogWrite() to control RGB brightness, digitalRead() to detect button presses, digitalWrite() to turn LEDs on and off, and for loops to repeat the lighting sequence. 


// Define the red channel pin.
int redPin = 11;

// Define the green channel pin.
int greenPin = 10;

// Define the blue channel pin.
int bluePin = 9;

// Define the yellow LED pin.
int led1 = 7;

// Define the white LED pin.
int led2 = 8;

// Define the button input pin.
int buttonPin = 2;

// Track whether the light show is running.
bool lightOn = false;

// Remember the previous button state.
int lastButtonState = HIGH;

// Run setup once when Arduino starts.
void setup() {
  // Set the red LED pin as an output.
  pinMode(redPin, OUTPUT);

  // Set the green LED pin as an output.
  pinMode(greenPin, OUTPUT);

  // Set the blue LED pin as an output.
  pinMode(bluePin, OUTPUT);

  // Set the yellow LED pin as an output.
  pinMode(led1, OUTPUT);

  // Set the white LED pin as an output.
  pinMode(led2, OUTPUT);

  // Enable the internal pull-up resistor.
  pinMode(buttonPin, INPUT_PULLUP);
}

// Repeat the main program continuously.
void loop() {
  // Check whether the button was pressed.
  checkButton();

  // Run the light show if it is enabled.
  if (lightOn) {
    // Cycle through the RGB pins from 11 to 9.
    for (int pin = 11; pin >= 9 && lightOn; pin--) {

      // Turn on the yellow LED.
      digitalWrite(led1, HIGH);

      // Turn off the white LED.
      digitalWrite(led2, LOW);

      // Gradually increase RGB brightness.
      for (int brightness = 0; brightness <= 255 && lightOn; brightness += 5) {
        // Set the current RGB channel brightness.
        analogWrite(pin, brightness);

        // Check whether the button was pressed.
        checkButton();

        // Wait for 30 milliseconds.
        delay(30);
      }

      // Continue only if the light show is still on.
      if (lightOn) {
        // Turn off the yellow LED.
        digitalWrite(led1, LOW);

        // Turn on the white LED.
        digitalWrite(led2, HIGH);

        // Gradually decrease RGB brightness.
        for (int brightness = 255; brightness >= 0 && lightOn; brightness -= 5) {
          // Set the current RGB channel brightness.
          analogWrite(pin, brightness);

          // Check whether the button was pressed.
          checkButton();

          // Wait for 30 milliseconds.
          delay(30);
        }
      }

      // Turn off the current RGB channel.
      digitalWrite(pin, LOW);
    }
  }

  // Check whether the light show is disabled.
  if (!lightOn) {
    // Turn off the red channel.
    digitalWrite(redPin, LOW);

    // Turn off the green channel.
    digitalWrite(greenPin, LOW);

    // Turn off the blue channel.
    digitalWrite(bluePin, LOW);

    // Turn off the yellow LED.
    digitalWrite(led1, LOW);

    // Turn off the white LED.
    digitalWrite(led2, LOW);
  }
}

// Define a function to check the button.
void checkButton() {
  // Read the button's current state.
  int buttonState = digitalRead(buttonPin);

  // Detect a new button press.
  if (buttonState == LOW && lastButtonState == HIGH) {
    // Toggle the light show on or off.
    lightOn = !lightOn;

    // Wait briefly to reduce button bouncing.
    delay(50);
  }

  // Save the current button state.
  lastButtonState = digitalRead(buttonPin);
}

04. Final Result

The final prototype creates an interactive light show. Pressing the button activates the lighting sequence, and pressing it again turns the lights off. The RGB LED gradually fades through different colors while the yellow and white LEDs create alternating lighting effects.

05. Additional Questions

Q1. PWM and Voltage Over Time

The analogWrite() function uses Pulse Width Modulation (PWM) to control LED brightness. A value of 64 corresponds to approximately 25% duty cycle, 128 corresponds to 50%, and 255 corresponds to 100%.

PWM rapidly switches the Arduino output between HIGH and LOW rather than producing a continuously varying analog voltage.

Q2. Total Current and Battery Life

To estimate the maximum LED current draw, I used Ohm's Law to calculate the current through all five LED channels when they are fully on simultaneously.

RGB Red (Pin 11): (5V - 2V) / 330Ω = 9.09mA

RGB Green (Pin 10): (5V - 3.2V) / 330Ω = 5.45mA

RGB Blue (Pin 9): (5V - 3.3V) / 220Ω = 7.73mA

Yellow LED (Pin 7): (5V - 2V) / 330Ω = 9.09mA

White LED (Pin 8): (5V - 2.85V) / 220Ω = 9.77mA

Total Current

I_total = 9.09 + 5.45 + 7.73 + 9.09 + 9.77

I_total = 41.13mA

The ATmega328P has an absolute maximum current rating of 40mA for a single I/O pin, not for the entire board. A more conservative design target is approximately 20mA or less per pin.

Each of my LED channels draws less than 20mA. The combined LED current of 41.13mA is also below the ATmega328P's 200mA absolute maximum total current rating. Individual pin-group current limits must also be respected.

Battery Life

Battery capacity = 1200mAh

Battery life = Battery capacity / Total current

Battery life = 1200mAh / 41.13mA

Theoretical LED-only battery life = approximately 29.2 hours

This is an idealized LED-only estimate assuming all five LED channels are fully on. The actual battery life would differ because the Arduino itself consumes power, the LEDs fade and flash instead of staying fully on, and power conversion introduces losses.

Q3. Measured LED Voltage

I used a multimeter set to DC voltage mode to measure the voltage across the white LED while it was turned on.

Measured forward voltage = 2.85V

The theoretical forward voltage of a white LED is typically around 3.0V to 3.3V. I used 3.2V as the reference value.

Difference = 3.2V - 2.85V = 0.35V

The measured voltage was 0.35V lower than the reference value. This difference may be due to variations in LED characteristics, operating current, and temperature.
